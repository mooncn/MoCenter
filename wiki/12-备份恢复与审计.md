# 12 备份恢复与审计

## 1. 数据备份

侧边栏 → **备份恢复** →「数据备份」点「创建备份」。

备份包包含服务端数据目录的关键内容：

- 主机登记与探针数据库、审计日志、备注与分享配置；
- `users.json`（账号口令哈希）、CA 证书与私钥、`agent.key`、Agent 客户端证书等**凭据**。

> ⚠️ 备份包含凭据：列表里会标记「含凭据」。请存放在受控位置（加密盘/受限共享），
> 不要在公开网盘或聊天工具里传输。

📷 **截图占位**：`备份恢复-列表`

## 2. 已有备份

| 操作 | 说明 |
|---|---|
| 下载 | 下载 zip 备份包到本机 |
| 查看清单 | 展开备份包内文件列表与大小（`manifest`） |
| 从该备份恢复 | ⚠️ 用备份覆盖当前数据；执行前会二次确认 |
| 删除 | 删除该备份文件，不可恢复 |

恢复注意事项：

1. 恢复会**替换**当前数据库与配置，恢复前建议先创建一份当前备份；
2. 恢复完成后按提示重启服务端；
3. 若备份来自另一套部署身份（不同 CA），Agent 需要重新换取证书（见 FAQ）。

## 3. 操作审计

侧边栏 → **操作审计**：记录所有敏感动作。

- **筛选**：时间范围（最近 1 小时 / 24 小时 / 全部等）、类别（命令执行、文件操作、认证、配置等）、
  状态（成功 / 失败 / 被拦截）、关键字（命令内容或主机）。
- **列表字段**：时间、操作人、主机、类别、操作内容、结果、来源 IP。
- **导出 CSV**：按当前筛选条件导出，便于留档或工单附带。
- **被拦截**：权限/策略拒绝的动作也会留痕（例如越权路径、被拒绝的注册），排查安全事件时重点看这一列。

📷 **截图占位**：`操作审计`

## 4. 常见场景

| 场景 | 做法 |
|---|---|
| 误删主机想找回 | 从最近的备份恢复（会覆盖期间的其它变更） |
| 只想知道“谁开的端口映射” | 审计按类别筛“端口映射” |
| 升级/改配置后异常 | 先看审计里该时间点的操作，再决定是否恢复 |
| 迁移到新服务器 | 备份 → 新机部署同版本 → 恢复 → 重启；Agent 地址需同步改（见 09/10） |
