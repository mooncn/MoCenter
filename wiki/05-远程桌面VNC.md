# 05 远程桌面（VNC）

侧边栏 → **远程桌面**。浏览器内嵌 noVNC 渲染，不需要在本机装 VNC 客户端。

## 1. 首次使用：一键安装 VNC

1. 选择**目标主机**（在线）。
2. 选择**连接模式**：
   - **标准**：Windows 以服务模式（UltraVNC `uvnc_service`）运行，可看锁屏/登录界面；Linux 侧为 x11vnc。
   - **交互会话模式**：在已登录的桌面会话里启动（Windows 需已登录且未锁屏）。
3. 点「一键安装 VNC」：服务端把安装包经长连接推给 Agent、安装并启动，成功后**自动回填口令**。
   （安装包来源：服务端 `data/packages` 或安装器自带；未配置公网下载时不会外联。）

📷 **截图占位**：`远程桌面-连接设置`

## 2. 连接与操作

- **VNC 端口**：默认 5900，一般不用改。
- **VNC 口令**：安装后自动填入；丢失时点「获取口令」从服务端读取（口令由服务端保管，不在页面明文存储）。
- 点「连接桌面」，几秒内出现画面。
- 画面操作：

| 操作 | 说明 |
|---|---|
| 鼠标 | 左键/右键/双击与本地一致；工具栏提供左/中/右键按钮 |
| 键盘 | 焦点在画布上时直接输入；`Ctrl+Alt+Del` 用工具栏按钮发送 |
| 全屏 | 连接成功后右下角悬浮按钮 → 全屏；`Esc` 或再点退出 |
| 缩放 | 工具栏可切换“适应窗口 / 标准”，高分屏可调 DPI 系数 |
| 连接信息 | 画布上方显示分辨率、码率、延迟 |

📷 **截图占位**：`远程桌面-画面`

## 3. 口令与安全

- 每次「一键安装 / 重置口令」都会**轮换 VNC 口令**，旧口令立即失效。
- 隧道只从 Server 转发到被控机的**回环地址**（默认 5900），不直接暴露 VNC 到网络；
  `-vnc-ports` 可收紧可连接的目标端口段（默认 `5900-5999`）。
- 分享出去的远程桌面链接会随分享过期/撤销立即失效（见 [11](11-展示配置与公开页.md)）。

## 4. 常见问题

| 现象 | 处理 |
|---|---|
| 连上后黑屏（Windows） | 会话被锁屏或处于登录界面：标准模式（服务模式）可看安全桌面；交互模式需用户先登录并解锁 |
| 连上后黑屏（Linux 无头机） | 确认 Xvfb/openbox 已启动（安装脚本会拉起），或改用带真实桌面的会话 |
| 提示“VNC 未就绪” | 点「一键安装 VNC」重新安装/启动；再看该机 Agent 日志里 vnc 相关行 |
| 口令错误 | 点「获取口令」取当前口令（安装/重置后口令会变） |
| 画面卡顿 | 降低桌面分辨率/关闭动画；跨公网时优先用「标准」模式并在服务端就近部署 |
