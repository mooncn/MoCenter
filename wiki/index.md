## 手册目录

MoCenter 由三部分组成：

- **Server（总控）**：一个进程，对外提供 Web 控制台（默认 `:8080`）与 Agent 长连接通道（默认 `:9000`）；
  主机清单、命令、隧道、审计、配置全部在这里。
- **Agent（被控端）**：Linux / Windows 服务，主动连回 Server，执行命令、回传探针、代理 VNC 与端口映射。
- **Web 控制台**：浏览器访问，默认自动签发自签名 HTTPS 证书（首次访问需信任）。

## 端口与地址

| 用途 | 默认 | 说明 |
|---|---|---|
| Web 控制台 / REST / WebSocket | `:8080` | 默认自动 HTTPS（自签，30 天）；可用 `-admin-tls-days 0` 关闭改走反向代理 |
| Agent 长连接 | `:9000` | TLS；Agent 首次用一次性令牌换取客户端证书（mTLS） |
| 端口映射 / VNC 隧道 | 按规则 | 隧道目标默认只允许被控机回环地址 |

## 阅读约定

- “控制台”指浏览器里的后台；路径写作「侧边栏 → 页面名」。
- 命令示例中 `$` 为 Linux shell、`> ` 为 Windows PowerShell / CMD（按上下文区分）。
- 标注 📷 的位置是**截图占位**，交付时可按图注补图。
- 涉及破坏性操作（删除、恢复、改监听）都会二次确认，文中单独标注 ⚠️。
