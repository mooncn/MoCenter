# 14 故障排查 FAQ

排查任何问题，先做这三件事，能解决八成情况：

1. **看审计**：控制台「操作审计」筛出对应时间点，确认是不是某次操作触发的；
2. **看日志**：服务端 `logs/mocenter-server.log`、被控机 Agent 日志（级别临时调 `info`）；
3. **对时间**：两端时钟差超过阈值时，注册/证书/令牌都会出各种看似无关的错。

---

## 登录与控制台

**Q：登录提示“用户名或口令错误”。**
- 确认用户名与安装时一致；初始口令文件只在**首次建号**时生效，改过密码后文件就作废了。
- 忘了口令：停服务 → 备份 `users.json` → 删掉它 → 用 `-password-file` 重新启动即可重建账号
  （会丢失账号绑定关系，OTP 需重绑）。

**Q：浏览器提示证书不受信任。**
- 默认是内置 CA 签发的自签证书：点“继续访问”即可；生产环境建议配置正式证书
  （`-web-tls-cert/-web-tls-key`）或前置 TLS 反向代理。

**Q：登录后很快被踢回登录页。**
- 会话保持时长到期（「系统配置 → 登录会话」）；或服务端重启过（Token 存在内存里）。

**Q：OTP 一直提示错误。**
- 手机时间不同步；动态码 30 秒一换，输入时注意剩余时间；同一验证码不能重复使用。

## Agent 接入

**Q：Agent 日志报 `注册报文时间戳偏差过大（xx h）`。**
被控机时钟与服务器差太多。校时后重连即可，**令牌仍然有效**：

```bash
chronyc makestep          # Linux（先确认 chronyd 在跑）
w32tm /resync             # Windows
```

**Q：`注册凭证校验失败`。**
- 令牌已过期 / 已被用过；或令牌签发时绑定的 `agent_id` 与本机不一致；
- 用共享密钥时，确认 Agent 的 `-agent-key` 与服务端 `<data>/agent.key` 内容一致；
- 重新签发一枚令牌最省事。

**Q：`TLS 连接失败且本机已持有客户端证书，拒绝降级`。**
服务端换过部署身份（CA）。二选一：
- 把控制台「Agent 接入」页的部署身份指纹填进 Agent 配置 `server_fingerprint`；
- 或删除 Agent 的 `creds/` 目录后重启，让 Agent 用令牌重新换取。

**Q：连上了 `:9000` 但很快掉线、主机显示离线。**
- 心跳间隔被配得过大（如 3600 秒），服务端会判超时；改回 `heartbeat: 30`；
- 网络抖动/中间设备空闲断连：确认没有 NAT 会话超时过短。

**Q：`已有实例在运行`。**
同一配置只能启动一个 Agent（单实例锁）。先停旧进程/服务，再启动新的。

**Q：Windows 上 `sc query MoCenterAgent` 显示 STOPPED。**
看 Windows 事件查看器「应用程序」里 `mocenter-agent` 的错误；常见是配置路径、证书文件或端口被占用。

## 文件管理

**Q：点进文件管理提示 `读取文件系统根失败：Agent 未在时限内返回结果（8s）`。**
Agent 版本过旧，不认识文件管理协议。升级 Agent 到与 Server 同批构建的版本。

**Q：点目录/跳转路径提示 `必须是绝对路径`（Windows 总控管理 Linux 主机）。**
旧版服务端用自身操作系统语义校验路径。升级服务端（当前版本按路径自身风格判断，
同时支持 POSIX / 盘符 / UNC）。

**Q：上传后提示“目标机未确认写入”。**
目标目录对 Agent 服务账号没有写权限（例如非 root 的 Agent 写 `C:\` 根或 `/root`）。
换有权限的目录，或提升 Agent 运行账号权限。

**Q：编辑按钮是灰的 / 提示超过上限。**
单文件超过「系统配置 → 文件管理 → 单文件上限」（默认 10 MiB，最大 64 MiB）；
调大上限，或下载后本地编辑。

**Q：打开文件是乱码。**
编码选错：在编辑器顶部换 `GB18030` / `UTF-16` 等，点「按此编码重新载入」；
保存时也按所选编码写回。

**Q：`/bin`、`/lib` 这类目录进不去。**
它们是“指向目录的符号链接”。升级 Web 前端后显示 `🔗📁`，可直接点击进入。

**Q：列表只显示一部分文件。**
- 单目录扫描上限 5000 项，超出会提示；
- 列表有分页（默认每页 100），确认是否停在某一页；
- 目录确实很大时建议进子目录或改用命令行。

## 远程桌面（VNC）

**Q：提示“VNC 未就绪”。**
先点「一键安装 VNC」安装/启动；仍失败看 Agent 日志里的 vnc 行（安装包来源、端口占用）。

**Q：能连上但黑屏。**
- Windows：会话被锁屏或在登录界面——用「标准」（服务模式）看安全桌面；
- Linux 无头机：确认 Xvfb/openbox 已拉起（安装脚本负责），或改用有真实桌面的会话。

**Q：口令错误。**
安装/重置都会轮换口令；点「获取口令」取当前口令，不要用旧口令。

## 端口映射 / 公开页 / 升级

**Q：端口映射外部连不上。**
- 公网端口没在防火墙/安全组放通；
- 被控机内网端口没监听；
- `-tunnel-hosts` 不允许该目标（默认只允许 127.0.0.1）。

**Q：公开页打不开 / 404。**
默认关闭。到「展示配置 → 全局开关」开启；若开启后仍空白，检查是否有可展示的主机被勾选。

**Q：分享链接提示“无效或已过期”。**
链接有有效期，且可被手动撤销；重新生成即可。

**Q：升级被拒绝。**
- 在线链接升级要求 Agent 配置 `-upgrade-pubkey`，且升级包用对应私钥签名；
- 本地 pkg 升级免签名，但包必须放在服务端 `data/packages`（或 `-pkg-dir`）且版本正确。

## 备份与恢复

**Q：恢复备份后 Agent 全部离线。**
备份来自另一套部署身份时 CA 也一起换了，Agent 的旧客户端证书不被信任。
让 Agent 重新换取证书（清 `creds/` 后用令牌接入），或恢复前确认备份来源。

**Q：恢复后服务端起不来。**
确认服务已停止后再覆盖数据目录；检查端口是否被旧进程占用；看日志里的配置解析错误。

## 磁盘与性能

| 现象 | 建议 |
|---|---|
| 数据库持续变大 | 探针原始数据只保留 7 天（更早归档后清理）；审计/备份按需清理 |
| 控制台打开慢 | 主机很多时用搜索/分页；公开页关闭或限制主机范围 |
| Agent 内存占用上涨 | 临时调高日志级别到 `info` 只用于排障，排完调回 `error` |

如仍无法定位，请提供：**操作时间点 + 相关主机 ID + 服务端/Agent 日志片段 + 审计截图**，便于快速定位。
