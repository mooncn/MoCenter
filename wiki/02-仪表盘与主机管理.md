# 02 仪表盘与主机管理

侧边栏 → **仪表盘**，这是登录后的默认页，也是日常最常用的一页。

## 1. 顶部指标

页面顶部是一排统计卡（在线主机、离线主机、平均 CPU、平均内存等，具体项随「展示配置」里的字段开关变化），
右侧有**时间窗**下拉：`1 小时 / 8 小时 / 24 小时`，影响趋势与延迟统计的取样范围。

📷 **截图占位**：`仪表盘-顶部指标与时间窗`

## 2. 主机列表

表格列（窄屏会自动折叠成卡片）：

| 列 | 说明 |
|---|---|
| 主机 | 备注名 + 主机名 + UUID；点「备注」可改名 |
| 状态 | 在线 / 离线（离线行有红点） |
| 趋势 | CPU / 内存迷你曲线，点开看该主机趋势弹窗 |
| CPU / 内存 / 磁盘 | 实时占用；容量与百分比分别受「展示配置」开关控制 |
| 公网 IP / 位置 | 由探针上报（离线时可能为空） |
| 最后在线 | 离线主机显示最后心跳时间 |
| 延迟 | 到探测目标的 RTT |
| 操作 | 远程终端 / 远程桌面 / 端口转发 / 分享 |

常用操作：

- **搜索/筛选**：顶部搜索框按主机名、备注、IP 过滤；表头可点排序（稳定字段）。
- **备注**：重命名只影响显示，不影响 Agent 身份与路由。
- **趋势弹窗**：点迷你曲线，看该主机在所选时间窗内的 CPU/内存/磁盘与延迟曲线。
- **分享**：生成一条带过期时间的分享链接，对方无需账号即可打开该主机的终端或桌面
  （详见 [11 展示配置与公开页](11-展示配置与公开页.md)）。

📷 **截图占位**：`仪表盘-主机列表`

## 3. 快捷进入远程控制

「操作」列三个按钮分别跳到：

- **远程终端**：Web 终端（见 [03](03-远程终端.md)）；
- **远程桌面**：VNC（见 [05](05-远程桌面VNC.md)）；
- **端口转发**：把本机内网端口临时映射到公网（见 [06](06-端口映射.md)）。

跳转时会自动带上目标主机，进入页面后无需再选。

## 4. 离线机器

侧边栏 → **离线机器**：按最后在线时间倒序列出当前离线的主机。

- 用途：清理已下线/已报废主机，避免仪表盘长期堆着僵尸记录。
- 删除只删服务端的登记信息；**不会**去目标机卸载 Agent。若该机以后重新上线，
  需要重新签发令牌接入。
- ⚠️ 删除不可恢复（会连同该主机的历史探针与备注一起清掉）。

📷 **截图占位**：`离线机器`

## 5. 主机状态判定

- 在线：Agent 与 Server 的长连接存在且心跳正常；
- 离线：连接断开，或超过心跳超时时间没收到心跳（Agent 默认 30 秒一次心跳，
  网络抖动会短暂显示离线，通常几秒内恢复）。

排查“一直离线”请看 [14 故障排查 FAQ](14-故障排查FAQ.md)。
