# 06 端口映射

侧边栏 → **端口映射**：把被控主机上的内网服务端口，经 Server 暴露到公网。
适合临时给外部调试一个 Web/SSH/数据库端口，不用改被控机网络。

## 1. 新建规则

填写后点「添加规则」：

| 字段 | 说明 |
|---|---|
| 目标主机 | 选择被控机（离线也可保存，待上线自动生效） |
| 公网端口 | Server 上监听的端口，如 `18080`；需未被占用且防火墙放通 |
| 内网服务端口 | 被控机上要暴露的端口，如 `80`、`3389` |
| 源 IP 白名单 | 可选，逗号分隔 IP/CIDR；留空表示不限制 |

📷 **截图占位**：`端口映射-新建规则`

## 2. 规则列表

| 列 | 说明 |
|---|---|
| 规则 ID / 公网端口 / 内网端口 | 映射关系 |
| 目标主机 | 主机备注名与 ID |
| 源 IP 白名单 | 为空显示“不限” |
| 状态 | 已启用 / 已禁用 |
| 操作 | 启用、禁用、删除 |

- **启用/禁用**：立即生效；禁用后公网端口停止监听。
- **删除**：规则与监听一起移除，不可恢复（不影响被控机上的服务本身）。
- 主机离线时规则可以保存，公网端口会先监听，Agent 上线后隧道自动生效。

## 3. 工作原理与限制

- 数据路径：公网客户端 → Server 监听端口 → 已认证的 Agent 长连接 → 被控机 `127.0.0.1:<内网端口>`。
- 隧道目标**默认只允许被控机回环地址**（防止把 Agent 当成内网扫描跳板）；
  需要转发到同网段其它机器时，必须在被控机 Agent 配置 `-tunnel-hosts` 显式放行。
- 只做 TCP 转发；UDP 不适用。
- 公网端口占用、防火墙、安全组需要自行确认，Server 不会自动改系统防火墙（安装器的监听切换除外）。

## 4. 安全建议

- 只映射必要的端口，用完及时禁用/删除；
- 尽量配置**源 IP 白名单**，不要把管理类端口（SSH、RDP、数据库）无限制暴露；
- 所有映射创建/删除都写操作审计，可回溯是谁在什么时候开的。

## 5. 常见问题

| 现象 | 处理 |
|---|---|
| 外部连不上，但本机 `127.0.0.1:公网端口` 能通 | 防火墙/安全组未放通该公网端口 |
| 规则启用但连接被重置 | 被控机内网端口未监听，或 Agent 的 `-tunnel-hosts` 不允许该目标 |
| 提示端口已被占用 | 换公网端口；先确认 Server 上无其它进程监听 |
