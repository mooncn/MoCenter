# 11 展示配置与公开页

侧边栏 → **展示配置**：控制站点的公开页开关、哪些主机/字段对外可见、站点标题与页脚。
公开页默认**关闭**；关闭时 `/` 只显示登录入口。

## 1. 全局开关

- **公开页**：开启后，未登录访问 `/` 即可看到汇总看板（只读，无任何操作入口）。
- 关闭后公开页立即不可访问（已打开的页面刷新即失效）。

## 2. 主机范围

选择哪些主机出现在公开页：

- 可逐台勾选 / 全选 / 全不选；
- 支持“按推荐默认（仅非敏感项）”，一键恢复为保守配置；
- 只是“是否对外可见”，不影响后台功能与数据采集。

## 3. 流量统计口径

| 口径 | 含义 | 适用 |
|---|---|---|
| 历史留存窗口内累计（推荐对外） | 只统计保留期内的流量 | 对外展示更贴近“近期实际” |
| 自设备启动以来累计 | 从 Agent 启动起累计 | 内网自用/对账 |

## 4. 展示信息项

按分组（性能 / 网络 / 系统等）逐项开关，例如：

- CPU 使用率、**内存使用率**、**内存大小**、**磁盘使用率**、**磁盘大小**、网络速率、在线时长、系统版本、公网 IP/位置等；
- 每项标记「对外可见 / 敏感」；标记为敏感的项默认关闭；
- **未开启的容量字段服务端根本不下发**（不是前端隐藏），避免“藏起来但接口能拿到”；
- 公网 IP 即使开启也会做部分掩码。

保存后公开页立即按新配置渲染。

## 5. 站点标题与页脚

- **网站标题**：浏览器标签与页面标题；
- **页脚内容**：支持 HTML（有白名单过滤），可放公司名、备案号、联系方式；
- 提供即时预览。

## 6. 公开页与分享链接

- 公开页：`https://<控制台>/`（站点入口）与 `/public`；点主机进入节点详情 `/public/node/<nodeId>`。
  只展示被允许的字段，匿名访问有独立限流。
- **分享链接**（邀请远程管理）：在仪表盘主机行点「分享」，生成带过期时间的链接，
  对方打开后直接进入该主机的终端/桌面（可设公网端口、内网端口等），无需账号。
  - 链接可随时撤销，撤销后已打开的会话立即断开；
  - 过期后打开会提示“分享链接无效或已过期”。

## 7. 审计

展示配置的每一次保存都写操作审计（分类在审计页可筛出），便于回溯“谁把哪个字段对外开了”。
