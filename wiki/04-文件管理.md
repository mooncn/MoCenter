# 04 文件管理

侧边栏 → **文件管理**：按**会话**对整台被管主机做文件运维（浏览、新建、重命名、复制/剪切/粘贴、
批量删除、上传下载、文本查看/编辑、Linux 权限与所有者）。

> 本页以 Agent 服务账号（Linux 通常 `root`、Windows `SYSTEM`/服务账户）执行，**不受 `-file-roots` 沙箱限制**。
> 所有新建/重命名/复制/移动/删除/上传/下载/保存/改权限都会写操作审计。

## 1. 连接与导航

1. **目标主机**：选择一台在线主机。
2. 点「连接文件管理」，默认进入根目录（Linux `/`；Windows 列出盘符，默认第一个盘）。
3. 顶部工具栏：
   - **路径**：输入绝对路径回车跳转（如 `/var/log`、`C:\Windows`）；
   - **根目录**：多盘符时可直接切换（Linux 只有一个 `/`，该下拉会隐藏）；
   - **上传文件 / 新建文件 / 新建文件夹 / 刷新 / 断开**。
4. 列表里点目录名进入；点「⬆ 上一级」返回（根目录没有该行）。

📷 **截图占位**：`文件管理-根目录`

## 2. 列表与分页

- 排序：**目录优先，再按名称**；每页默认 **100 条**，可在「系统配置 → 文件管理 → 列表每页条数」调整（20–1000）。
- 顶部信息条与列表底部各有「上一页 / 下一页」；页码越界会自动回落到最后一页。
- 单目录扫描上限 **5000 项**，超过时底部提示“仅扫描前 5000 项”——此时请进入子目录或改用命令行。
- **全选**：勾选框列可以逐条选，点「全选」（条目超过一页时显示「全选本页」）只选当前页。
- 选中后出现批量工具条：复制 / 剪切 / 删除 / 取消选择。

## 3. 顶部磁盘信息

信息条右侧显示当前分区的：`文件系统（NTFS / ext4 / xfs …）`、使用率、剩余/总容量；
点它会打开「磁盘与分区」弹窗，列出该主机全部分区。每次刷新目录都会更新。

## 4. 常规操作

| 操作 | 入口 | 说明 |
|---|---|---|
| 打开目录 | 点目录名 / 右击「打开」 | 符号链接到目录也能进入（显示 `🔗📁`） |
| 下载 | 行内「下载」或右击 | 单文件上限 64 MiB |
| 上传 | 工具栏「上传文件」 | 上传到**当前目录**；同名会先确认覆盖 |
| 新建 | 工具栏「新建文件 / 新建文件夹」 | 名称不能含路径分隔符 |
| 重命名 | 行内「重命名」或右击 | **只改同目录名字**；目标已存在则拒绝（不覆盖） |
| 删除 | 行内「删除」或右击 | 目录会**递归删除**，需二次确认 |
| 属性 | 右击「属性」 | 类型、大小、修改时间、权限、所有者:分组、完整路径 |

## 5. 剪贴板（复制 / 剪切 / 粘贴）

1. 勾选条目（可多选）→「复制」或「剪切」。
2. 进入目标目录（或右击目标目录选「粘贴到该目录」）→ 点「粘贴」。
3. 剪贴板最多保存 **100 项**；点「粘贴」右侧的「列表」可展开查看，**每页 10 项**。

细节：

- 粘贴前会检查同名冲突，弹窗确认后才覆盖（同名文件被覆盖、同名目录合并）。
- 已在目标目录里的条目会自动跳过。
- **剪切粘贴 = 移动**；复制粘贴后剪贴板保留，剪切粘贴后清空。
- 剪贴板属于当前会话，断开/超时后清空。

## 6. 文本查看与编辑

支持 `.log` `.txt` `.md` `.ini` `.conf` `.xml` `.json` `.yaml` `.php` `.js` `.sh` `.py` 等文本格式；
Linux 上**无扩展名且非可执行**的文件（`/etc/hosts`、`sshd_config`、`/var/log/messages`）同样可以打开。

- **查看**（右击 → 查看）：默认**只读**打开，适合看日志、防误改。
- **编辑**（行内「编辑」或右击 → 编辑）：可写；窗口内也能随时勾选/取消「只读」。
- **编码**：
  - 打开时自动检测（BOM → UTF-8 → GB18030 / Big5 / Shift_JIS → Windows-1252 兜底）；
  - 顶部下拉可改编码，点「按此编码重新载入」按新编码重读；
  - 保存按**当前选择的编码**写回（`UTF-8 BOM`、`UTF-16LE/BE` 会自动补 BOM）；内容里有该编码不支持的字符会报错。
- **大小限制**：默认 **10 MiB**，在「系统配置 → 文件管理 → 单文件上限」调整（1–64 MiB）；
  超限的文件「编辑」按钮置灰，只能下载。
- **二进制文件**（含 NUL/大量控制字符）会被拒绝，不会当文本渲染。
- 保存采用“同目录临时文件 + rename”原子替换，保留原权限位；关闭时若有未保存修改会二次确认。

📷 **截图占位**：`文件管理-查看模式`（编码下拉 + 只读勾选）

## 7. 右击菜单

右击任意条目（或已选中的一整组）：

| 菜单项 | 适用 | 说明 |
|---|---|---|
| 打开 | 目录 / 链接到目录 | 进入 |
| 查看 / 编辑 | 文件 | 只读打开 / 可写打开 |
| 下载 | 文件 | 单文件 64 MiB 上限 |
| 复制 / 剪切 | 全部 | 放入剪贴板 |
| 粘贴 / 粘贴到该目录 | 剪贴板非空 | 目录上直接粘贴进去 |
| 重命名 | 单个条目 | 不支持多选 |
| 删除 | 全部 | 递归删除 + 确认 |
| 权限 / 所有者… | 仅 Unix | 见下一节 |
| 属性 | 全部 | 详情弹窗 |

菜单支持 `Esc`、点击空白、滚动、缩放自动收起，靠近窗口边缘会自动夹回。

## 8. Linux 权限与所有者

- Linux/macOS 主机列表多一列「权限」（如 `rw-r--r--`），悬停可看 `owner:group（uid:gid）`。
- 右击 →「权限 / 所有者…」：
  - 三组勾选（所有者 / 同组 / 其他 × 读/写/执行），与八进制输入双向联动；
  - 所有者、分组支持**用户名/组名或数字 UID/GID**，留空表示不改；
  - 点「应用」保存，成功后列表立即刷新。
- 拒绝修改**文件系统根**（`/` 或盘符根）的权限/所有者；`chown` 跟随符号链接。
- Windows 主机不显示权限列与该项菜单（Agent 对直接调用返回“当前平台不支持”）。

## 9. 会话与超时

- **无操作 20 分钟**自动断开，**没有累计时长上限**（一直在操作就不会被踢）。
- 每台主机最多 2 个会话、全局 8 个；同一操作员可同时开多个会话。
- 页面右上角「空闲断开 mm:ss」是服务端剩余时间；主动点「断开」立即释放。
- 状态查询（每 30 秒）不会刷新活跃时间，所以“页面开着但不动”仍会按时断开。

## 10. 常见问题

| 现象 | 原因与处理 |
|---|---|
| 连上后立即报超时（8 秒内无响应） | Agent 版本过旧、不认识文件管理协议：升级到与 Server 同批构建的 Agent |
| “必须是绝对路径” | 旧版服务端用自身操作系统语义校验路径（Windows 总控管 Linux 主机时 `/etc` 会被判成相对路径）；升级 Server |
| 上传成功但列表里没有 / 报“未确认写入” | 目标目录没有写权限（Agent 服务账号）；换目录或提升权限。错误详情见该机 Agent 日志 |
| “文件超过在线编辑上限” | 在「系统配置 → 文件管理」调大上限（最大 64 MiB），或下载后本地编辑 |
| 打开文本是乱码 | 编码选错：顶部下拉换 GB18030 / UTF-16 等，点「按此编码重新载入」 |
| 打不开 `/bin`、`/lib` 这类目录 | 老版本前端不支持符号链接目录；升级 Web 前端后显示 `🔗📁` 可直接进入 |
| 删除按钮点了没反应 | 目录递归删除需要确认弹窗；确认后仍失败请看审计与 Agent 日志（权限/占用） |
