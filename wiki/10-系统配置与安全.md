# 10 系统配置与安全

侧边栏 → **系统配置**。页面分 5 个可折叠分区，改动即时生效并落盘到服务端配置文件。
高风险项（监听地址）需要**再次输入当前密码**。

## 1. 账号与安全

- **修改密码**：输入当前密码 + 新密码（至少 12 位）。改完立即生效，其它已登录会话会在下次请求时失效/按新策略续期。
- **OTP 动态验证码**：
  - 「绑定」：扫码或手工录入密钥，输入一次 6 位码确认；
  - 「重新生成 / 关闭」都需要再次验证密码；
  - 绑定后登录必须带 6 位码；同一验证码不能重复使用（防重放）。

📷 **截图占位**：`系统配置-账号与安全`

## 2. 登录会话

选择 **保持时长**（1 小时 / 12 小时 / 24 小时 / 7 天 / 15 天 / 30 天），点「保存会话时长」。

- 新登录按新时长计时；**现有会话在下次请求时按新时长续期**，缩短会立即收紧已有会话。
- 过期后前端自动退出到登录页。

## 3. 文件管理

| 字段 | 默认 | 说明 |
|---|---|---|
| 单文件上限（MiB） | 10 | 在线预览/编辑的大小上限，范围 1–64；超限只能下载 |
| 列表每页条数 | 100 | 文件列表分页大小，范围 20–1000 |

保存后对**新打开/刷新的**文件列表与编辑请求生效（已打开的编辑器不受影响）。

## 4. Agent 监听配置

修改 Agent 长连接监听的 Host / 端口：

1. 先放通防火墙 / 安全组的新端口（页面有醒目提示）；
2. 填 Host（留空 = 全部网卡）、端口；
3. 输入**当前登录密码**并勾选风险确认；
4. 点「保存并切换 Agent 监听」。

执行顺序：先绑定新监听 → 再向在线 Agent 下发新地址（`ServerAddrUpdate`）→ 确认的主机断线重连；
绑定失败不会改动任何 Agent，切换失败会自动恢复旧地址。旧版 Agent 不会回执，仍保持原连接。

⚠️ 如果 Server 前面有 NAT/端口映射，改端口后别忘了同步映射规则。

📷 **截图占位**：`系统配置-Agent监听`

## 5. 后台配置

修改 Web 控制台监听地址（Host / 端口），同样需要当前密码：

- 同端口只换 Host：响应返回后切换，失败自动恢复；
- 换端口：新监听先就绪再关闭旧入口，当前页面会断开，需用新地址重新访问；
- 若用反向代理对外，建议保持 `:8080` 只监听内网，由代理终结 TLS。

## 6. 服务端日志

- 配置文件 `log_level` 或启动参数 `-log-level`，级别 `off / error / warn / info`，**服务端默认 `info`**。
- `off` 只关闭运行期日志，启动致命错误仍会打印。
- 日志按大小轮转（8MB × 2 份）；Windows 安装版日志在数据目录 `logs\` 下。

## 7. 安全基线（建议逐项确认）

- [ ] 已修改初始口令，并绑定 OTP；
- [ ] 会话保持时长按实际需要尽量缩短；
- [ ] Agent 全部改用一次性令牌；`-disable-shared-agent-key` 已开启；
- [ ] 需要更强约束时开启 `-require-agent-cert`（强制 mTLS）；
- [ ] Web 控制台只对内网/办公网开放，或经 TLS 反向代理；
- [ ] 监听地址变更走控制台（自动写入配置），而不是手动改二进制参数；
- [ ] 定期导出备份（见 [12](12-备份恢复与审计.md)），备份包含凭据，注意保管。
