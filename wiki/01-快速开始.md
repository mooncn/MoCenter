# 01 快速开始

## 1. 环境要求

| 角色 | 支持平台 | 说明 |
|---|---|---|
| Server | Windows 10/11、Windows Server 2016+、主流 Linux（x86_64） | 单进程即可运行，默认自带 SQLite 与内置 CA |
| Agent | Linux（systemd）、Windows（服务） | 需要能主动连到 Server 的 `:9000` |
| 浏览器 | Chrome / Edge 最新版 | 控制台与远程桌面（noVNC） |

网络要求：

- 被控机 → Server：`9000/tcp` 可达（跨网段请先放通防火墙 / 安全组）。
- 管理员 → Server：`8080/tcp`（或你配置的反向代理入口）。

## 2. 安装 Server

### 方式 A：Windows 安装包（推荐给 Windows 用户）

运行 `MoCenter-Setup-<版本>.exe`，在「角色」页选择 **Server**：

1. 选择安装目录（默认 `C:\Program Files\MoCenter`）。
2. 设置管理员账号与口令，并选择**日志级别**（默认 `error`；排障时可临时改 `info`）。
3. 完成安装后，服务以 Windows 服务 `MoCenterServer` 运行，监听 `:8080`（Web）与 `:9000`（Agent）。

常用命令（管理员 PowerShell）：

```powershell
Get-Service MoCenterServer
Start-Service MoCenterServer
Restart-Service MoCenterServer
Get-Content "C:\ProgramData\MoCenter\server\logs\mocenter-server.log" -Tail 50
```

### 方式 B：压缩包 / 二进制（Windows 或 Linux）

```bash
# 解压后直接运行（首次会自动生成配置 ./server.json）
./mocenter-server \
  -listen :9000 -http :8080 \
  -user admin -password-file ./initial-password.txt \
  -data ./data -web ./web
```

- `-password-file` 指向一个权限 `0600` 的文件，仅用于**首次创建账号**；文件读完建议删除。
- 生产环境建议交给 systemd / Windows 服务托管（安装包已内置）。
- 需要 HTTPS 且不想用自签证书时：配置 `-web-tls-cert/-web-tls-key`，或 `-admin-tls-days 0` 后走 Nginx/Caddy 反向代理。

📷 **截图占位**：`安装向导-角色选择`（Server/Agent 单选，下方为日志级别下拉）

## 3. 首次登录

浏览器打开 `https://<服务器地址>:8080/`（自签证书首次访问需点「继续访问」），进入登录页：

- 用户名 / 口令：与安装时设置的一致；
- 若账号已绑定 OTP，需同时填写 6 位动态验证码。

初始口令的位置：

| 部署方式 | 位置 |
|---|---|
| Windows 安装包 | 安装向导里设置；日志会提示配置文件位置 |
| 二进制 + `-password-file` | 你指定的文件（读一次即失效） |
| 未显式指定 | 数据目录下的 `initial-password.txt` |

登录后默认进入「仪表盘」。右上角有「退出登录」。

📷 **截图占位**：`登录页`

## 4. 接入第一台主机

推荐用**一次性注册令牌**（一台一份、用后即废）：

1. 「Agent → 通用部署（Agent 接入）」→ 选择「Linux」或「Windows」→ 点「签发令牌」。
   - 可以填写固定的 Agent 名称（如 `web-01`）；留空则用设备 UUID 作为身份。
2. 按页面生成的命令在目标机上执行（Linux 示例）：

```bash
curl -fsSL https://<控制台地址>/api/packages/agent-linux-amd64 -o /tmp/mocenter-agent
chmod +x /tmp/mocenter-agent
sudo /tmp/mocenter-agent \
  -server <服务器IP>:9000 \
  -agentid web-01 \
  -enroll-secret <页面给出的一次性令牌> \
  -daemon
```

3. 令牌只用于**首次换取客户端证书**；换取成功后会自动清空，后续连接直接携带证书。

也可以让控制台通过 SSH 帮你装（要求 Linux 主机开放 SSH）：

1. 「Agent → SSH 部署（Linux）」；
2. 填主机地址、SSH 端口、登录用户、认证方式（密码或私钥）、可选的 sudo 密码；
3. 建议先点「测试连接」，把回显的主机密钥指纹核对后填入「主机密钥指纹」——填写后即**强制钉扎**；
4. 点部署，等待日志显示 Agent 上线。

📷 **截图占位**：`Agent接入-签发令牌`

## 5. 验证

回到「仪表盘」，应能看到该主机状态为**在线**，并开始出现 CPU / 内存 / 磁盘与延迟数据。
点主机行的快捷操作可直接进入「远程终端 / 远程桌面 / 端口转发」。

## 6. 收尾（建议）

- 在「系统配置 → 登录会话」把保持时长调到合适值（默认 12 小时）。
- 在「系统配置 → 账号与安全」绑定 OTP。
- 站点需要对外展示指标时，到「展示配置」开启公开页（默认关闭）。
- 全部主机迁移到一次性令牌后，给 Server 加 `-disable-shared-agent-key` 关闭共享注册密钥。

> ⚠️ 如果安装包/二进制里不带 `-upgrade-pubkey`，Agent 会拒绝**在线链接升级**（这是默认安全态）；
> 服务端本地 `pkg` 升级仍然可用。详见 [07 运维操作](07-运维操作.md)。
