# 03 远程终端

侧边栏 → **远程终端**。基于 xterm.js 的持久交互会话，支持连续命令、全屏程序与控制键。

## 1. 建立会话

1. 选择**目标主机**（只列在线主机）。
2. 选择 **Shell 环境**：`自动推断`（默认）、`bash` / `sh`（Linux）、`cmd` / `powershell`（Windows）。
3. 点击连接，终端区出现提示符即可输入。

📷 **截图占位**：`远程终端-会话`

## 2. 使用要点

| 操作 | 说明 |
|---|---|
| 输入命令 | 直接敲，回车执行；输出实时流式回传 |
| 复制 / 粘贴 | 鼠标拖选后用浏览器快捷键复制；粘贴用 `Ctrl+V`（部分浏览器需 `Ctrl+Shift+V`） |
| 控制键 | `Ctrl+C`、`Ctrl+D`、`Ctrl+L` 等按终端语义转发 |
| 清屏 | 工具栏「清屏」只清前端显示，不影响远端会话 |
| 断开 | 工具栏「断开」结束会话；关闭页面同样会断开 |

- 会话是**持久**的：连续执行多条命令、进入 `top` / `vim` 等全屏程序都可以。
- 页面显示的是当前登录操作员的会话；离开页面后，远端进程会随会话结束而终止。

## 3. 与“运维操作 → 批量命令”的区别

| 场景 | 建议入口 |
|---|---|
| 交互式排障、看输出、进全屏程序 | 远程终端（本页） |
| 一次性命令、多台主机批量执行、要回执归档 | 「运维操作 → 批量命令」（见 [07](07-运维操作.md)） |

## 4. 安全说明

- 终端以 Agent 服务账号身份执行（Linux 通常是 `root`，Windows 是 `SYSTEM` 或服务账户）；
- 所有命令与结果会写入操作审计（含操作人、主机、时间；输出按审计策略脱敏/截断）；
- 命令通道只走已认证的 mTLS 长连接，不开放被控机入站端口。

## 5. 常见问题

- **连上但没有提示符**：确认所选 Shell 在目标机存在（Windows 老系统可能没有 `powershell`，改 `cmd`）。
- **中文乱码**：Windows 控制台默认代码页可能不是 UTF-8，可在命令前执行 `chcp 65001`。
- **大输出卡顿**：交互终端适合看现场；导出大日志请用「文件管理」下载或「批量命令」并落文件。
