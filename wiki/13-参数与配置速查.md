# 13 参数与配置速查

## 1. 服务端命令行参数

| 参数 | 默认 | 说明 |
|---|---|---|
| `-listen` | `:9000` | Agent 长连接监听地址 |
| `-http` | `:8080` | Web 控制台 / REST / WebSocket 监听地址 |
| `-web` | 空 | 前端静态目录；留空则不托管前端 |
| `-data` | `./data`（安装版为数据目录） | 数据目录：数据库、审计、CA、上传中转 |
| `-user` | 空 | 登录用户名（设置后启用账号登录） |
| `-password-file` | 空 | 初始口令文件（0600，仅首次建号用，推荐） |
| `-password` | 空 | 初始口令（不推荐：会出现在 `ps` / `systemctl show`） |
| `-totp-secret` | 空 | 预置 TOTP 密钥（base32），设置后登录需动态码 |
| `-agent-key` | 空 | Agent 共享注册密钥；留空自动生成到 `<data>/agent.key` |
| `-require-agent-cert` | `false` | 强制 Agent 携带客户端证书（关闭“先换取”） |
| `-disable-shared-agent-key` | `false` | 关闭共享注册密钥，只认一次性令牌 |
| `-allow-unauthenticated-agents` | `false` | ⚠️ 允许无凭证注册（仅迁移期） |
| `-whitelist` | 空 | 控制台访问 IP 白名单（逗号分隔，支持 CIDR） |
| `-trusted-proxies` | 空 | 可信反代网段，用于还原客户端真实 IP |
| `-tls-cert` / `-tls-key` | 空 | Agent 通道 TLS 证书/私钥（留空用内置 CA 自动签发） |
| `-ca-cert` | 空 | mTLS 客户端 CA（提供后启用双向认证） |
| `-web-tls-cert` / `-web-tls-key` | 空 | 控制台 HTTPS 证书（留空自动签发自签证书） |
| `-admin-tls-days` | `30` | 控制台自动 HTTPS 证书有效期；`0` 关闭（走反代时用） |
| `-server-name` | 空 | 部署身份名（写入 CA，区分多套总控） |
| `-token-ttl` | `12h` | 登录会话 Token 有效期 |
| `-vnc-ports` | `5900-5999` | VNC 隧道/探测允许的目标端口段（显式传空串=不限制） |
| `-upgrade-pubkey` | 空 | 升级包 Ed25519 公钥（hex 或文件）；留空则拒绝在线链接升级 |
| `-pkg-dir` | `<data>/packages` | 本地升级包目录 |
| `-file-edit-max-mb` | `10` | 文件在线编辑上限（MiB，1–64） |
| `-log-level` | `info` | `off` / `error` / `warn` / `info` |
| `-mmdb` | 空 | 离线 GeoIP 库路径（无外网时用） |
| `-proxy-ip` | 空 | 访问境外接口（ip-api.com）的加速代理前缀 |
| `-config` | `./server.json` | 配置文件路径（首次启动自动生成） |

## 2. Agent 命令行参数

| 参数 | 默认 | 说明 |
|---|---|---|
| `-server` | 空 | 服务端地址 `host:port` |
| `-agentid` | 空 | Agent 名称/ID（可变，仅显示与路由）；留空用设备 UUID |
| `-uuid` | 自动探测 | 设备身份 UUID |
| `-hb` | `30` | 心跳间隔（秒） |
| `-probe` | `10` | 探针采集周期（秒） |
| `-daemon` | `false` | 守护模式（后台运行、崩溃自启） |
| `-tls` / `-insecure` | `false` | 启用 TLS / 跳过证书校验（仅测试） |
| `-agent-key` | 空 | 共享注册密钥（与服务端 `agent.key` 一致） |
| `-enroll-secret` | 空 | 一次性注册令牌（换取证书后自动清空） |
| `-server-fingerprint` | 空 | 服务端身份公钥指纹（免 CA 文件的钉扎校验） |
| `-client-cert` / `-client-key` / `-ca-cert` | 空 | 手工 mTLS 证书（一般由换取流程自动落盘） |
| `-upgrade-pubkey` | 空 | 允许在线升级时必填（Ed25519 公钥） |
| `-file-roots` | `<配置目录>/files` | **文件分发**允许的读写目录（逗号分隔） |
| `-tunnel-hosts` | 空 | 隧道允许访问的非回环地址（默认只允许 127.0.0.1） |
| `-latency-targets` | 空 | 延迟探测目标：`icmp:1.1.1.1,tcp:1.1.1.1:443,http:https://…` |
| `-log-level` | `error` | `off` / `error` / `warn` / `info`（可由服务端远程下发） |
| `-allow-public-package-download` | `false` | 允许从公网取 VNC/驱动安装包 |
| `-creds-dir` | `<配置目录>/creds` | 客户端证书目录 |
| `-config` | `<配置目录>/mocenter-agent.json` | 配置文件路径 |

## 3. 服务端配置文件字段（`server.json`）

| 字段 | 对应参数 |
|---|---|
| `listen` / `http` | `-listen` / `-http` |
| `listen_managed` / `http_managed` | 是否由控制台接管监听（改过监听后为 true） |
| `whitelist` / `trusted_proxies` | `-whitelist` / `-trusted-proxies` |
| `web_dir` | `-web` |
| `data_dir` / `pkg_dir` | `-data` / `-pkg-dir` |
| `user` / `admin_password_file` | `-user` / `-password-file` |
| `password` / `totp_secret` | 恒为空（不落盘） |
| `agent_key` | `-agent-key` |
| `tls_cert` / `tls_key` / `ca_cert` / `insecure` | 对应同名参数 |
| `web_tls_cert` / `web_tls_key` / `admin_tls_days` | 控制台 HTTPS |
| `server_name` | `-server-name` |
| `token_ttl` | `-token-ttl` |
| `vnc_ports` / `upgrade_pubkey` | 对应参数 |
| `file_edit_max_mb` / `file_list_page_size` | 控制台「系统配置 → 文件管理」 |
| `require_agent_cert` / `disable_shared_agent_key` / `allow_anon_agents` | 注册与认证开关 |
| `log_level` | `-log-level` |
| `mmdb_path` / `proxy_ip` | 对应参数 |

> 命令行显式参数优先于配置文件；控制台修改的项（监听、会话时长、文件管理）会写回配置文件。

## 4. HTTP API 速查

除 `/api/login`、`/api/health`、`/api/server-info`、`/api/branding`、`/api/public/*`、`/api/share/*` 外，
其余都要求 `Authorization: Bearer <token>`。

| 分类 | 路径 |
|---|---|
| 认证 | `POST /api/login`、`POST /api/logout`、`POST /api/password`、`/api/otp/setup|enable|disable` |
| 会话 | `POST /api/session/handoff`、`POST /api/session/handoff/consume` |
| 主机 | `GET /api/agents`、`/api/agents/history`、`/api/agents/remark`、`/api/agents/delete`、`/api/agents/log-level` |
| 命令 | `/api/command`、`/api/command/batch`、`/api/command/close` |
| 终端/桌面 | `/ws`（终端 WebSocket）、`/vnc-ws`（桌面隧道）、`/api/vnc/probe|install|status|password` |
| 文件 | `/api/files/session`、`/session/close`、`/list`、`/op`、`/upload`、`/download`、`/text` |
| 端口映射 | `/api/portmap/rules`、`/api/portmap/op` |
| 分享 | `/api/shares`、`/api/shares/revoke`、`/api/share/*`（免登录，凭分享码） |
| 审计 | `GET /api/audits`（支持筛选与导出） |
| 升级 | `POST /api/upgrade` |
| 接入 | `/api/enroll/tokens`、`/api/enroll/token/revoke|delete`、`/api/enroll/cert/reset`、`/api/enroll/shared-key/rotate` |
| 站点 | `/api/site/config`、`/api/site/config/reset`、`/api/site/hosts`、`/api/branding`、`/api/public/*` |
| 系统 | `/api/system/config`、`/session`、`/file-edit`、`/file-list`、`/agent-listen`、`/http-listen` |
| 备份 | `/api/backup/*` |

## 5. 常用运维命令

Linux：

```bash
systemctl status mocenter-agent --no-pager
journalctl -u mocenter-agent -n 50 --no-pager
systemctl restart mocenter-server
firewall-cmd --add-port=9000/tcp --add-port=8080/tcp   # 临时放通
chronyc tracking && chronyc makestep                   # 校时
```

Windows（管理员 PowerShell）：

```powershell
Get-Service MoCenterServer, MoCenterAgent
Restart-Service MoCenterServer
Get-Content "C:\ProgramData\MoCenter\server\logs\mocenter-server.log" -Tail 80
w32tm /resync
```
